# Журнал решений

Принятые инженерные решения фиксируются здесь **только после явного решения владельца**. Зелёный CI/RepoGuard, PR merge или наличие требования сами по себе не означают предметной приёмки.

## Зафиксированная организация проекта
- Отопление, ГВС и холодное водоснабжение проектируются в `home-heat-water`.
- Электрические решения остаются в `aes`.
- Для расчётного кода используется TypeScript; RepoGuard 4.x подключается по immutable SHA.

## Не принято
Конкретный новый ТА, 2 × 300/400 л, паспортный срок службы, материал и толщина, отказ от анода, отдельный электрокотёл, изменение ГВС, водоподготовка, исполнительные схемы.

## Инвентаризация 27.10.2026 — новые решения не принимались
Вся добавленная планировка, описание гидравлики, шесть первоначальных пользовательских пожеланий и зарегистрированные недостатки имеют тип `as-is` / `proposed`, а **не** техническую приёмку. Не приняты: новый тип БКН, схема устранения воздушной пробки, изменение дымохода/вентиляции, конкретный новый ТА и автоматическое связывание требований с числовыми пределами, которых владелец не указывал.

## Новые идеи 27.10.2026 — **не выбор архитектуры**

- 75 × 170 см — доступное место под ёмкости внутри, под наклонным потолком.
- Рассматриваются **два одинаковых отключаемых ТА**; **один ТА с отдельным БКН**; **ТА снаружи**; **комбинированный ТА/ГВС**. Все варианты — `proposed / under study`.
- Приоритет ГВС над комфортным отоплением, разрешён дневной электрический догрев. Эти потребности фиксируются независимо от выбранной топологии.
- Вопрос летнего режима **«нагревать только БКН, не ТА»** — существенный критерий при отборе вариантов, а не аргумент в пользу непроверенной комбинированной ёмкости.
