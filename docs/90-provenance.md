## Классы утверждений

1. **Сообщено владельцем:** материалы и размеры as-is, эксплуатационные наблюдения, потребности.
2. **Наблюдается на фото:** внешний вид узлов, расположение и доступность; фото **не доказывает** внутреннюю схему и параметры.
3. **Предположение:** причины запаха, ржавчины, пробки, ожидаемый срок службы; требуют проверки.
4. **Вычислено:** TypeScript-модель с ограничениями и входными данными.
5. **Документировано изготовителем:** только с конкретным паспортом/версией/условиями.
6. **Физически проверено:** только по протоколу измерений/испытаний.

Факты, гипотезы, нормативные цели и предложенные проектные решения не объединять. Для неизвестных условий допускается только `UNKNOWN`, не `PASS`.
