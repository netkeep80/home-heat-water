# Потребности и критерии

**Черновик обсуждения.** Список потребностей не равен принятым техническим решениям и не подменяет канонические `requirements/*.rg.yaml` для проверки RepoGuard.

| ID | Потребность | Будущее свидетельство |
|---|---|---|
| HW-R01 | Отопление дома 80 м² ночью электричеством с дозагрузкой дров | Температурные/энергетические измерения |
| HW-R02 | Замена ТА не должна ухудшить комфорт при нынешних 550 л | Сопоставимый энергетический баланс |
| HW-R03 | Электронагреватель заменяется без слива основных ТА | Проверяемая сервисная схема |
| HW-R04 | Низкий риск внезапной течи корпуса ТА | Материал, производство, контроль швов, вода |
| HW-R05 | До 50 лет — целевой горизонт корпуса, **не обещание производителя** | Обоснование долговечности, осмотр/мониторинг |
| HW-R06 | Исключить обязательную ежегодную замену расходного анода, если обосновано | Регламент и письменная позиция изготовителя |
| HW-R07 | Достаточный объём и скорость нагрева ГВС | Сценарии водоразбора и замеры |
| HW-R08 | Водоподготовка под собственную скважину | Актуальная лаборатория и паспорта оборудования |
| HW-R09 | Энергопотребление согласовано с AES | Таблица режимов и границ |
| HW-R10 | Проверены необходимые защиты котла и гидравлики до реконструкции | Проектная проверка по паспортам |

Требования к ТА: точная марка всех водоконтактных деталей, расчёт корпуса, качество и контроль сварки, внутренняя пассивация, регламент обслуживания, температура/давление, съёмность изоляции и возможность внешнего нагрева. Решение фиксируется владельцем только после подтверждения.
