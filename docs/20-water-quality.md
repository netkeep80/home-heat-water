# Вода из скважины: исходные свидетельства

**Не исследование воды владельца.** Данные двух соседских проб, предоставленные в обсуждении 26.10.2026; исходные чужие документы намеренно не публикуются.

| Показатель | Соседская проба, фото (дата неизвестна) | Проба «Дуброво», 03.06.2021 |
|---|---:|---:|
| pH | 7,7 | 7,4 |
| Жёсткость, мг-экв/л | 26 | 9 |
| Хлориды, мг/л | 7 | 8 |
| Железо, мг/л | 0,05 | 0,60 |
| Сухой остаток, мг/л | 604 | 440 |
| Сульфаты, мг/л | 120 | 69 |
| Щёлочность, мг-экв/л | 4,5 | 6,1 |

Низкие хлориды благоприятны для рассмотрения 316L, но не доказывают 50-летний ресурс. Данные очень разнятся по жёсткости; у фотографии есть возможное расхождение минерализации с указанными кальцием и магнием, требующее перепроверки исходных единиц. Высокая жёсткость важна для обслуживаемости внешних нагревателей и ГВС. Следующее свидетельство: современный анализ собственной скважины, включая pH, Cl⁻, жёсткость, щёлочность, Fe, электропроводность, сульфаты.
